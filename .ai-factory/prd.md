# MoneyPersona

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
12개 질문으로 나의 소비 성향을 '알뜰형 다람쥐' 같은 8가지 캐릭터로 진단해주는 재테크 성향 테스트

## Problem
MBTI, 성향테스트는 넘쳐나지만 정작 내 소비/저축 습관을 재미있게 진단해주는 금융형 테스트는 없어 재테크 시작 전 자기 이해가 부족함

## Target Users
재테크에 관심 있고 SNS 공유를 즐기는 20-30대

## Core Features
1. 12문항 소비성향 진단 퀴즈
2. 8가지 소비 캐릭터 결과 카드
3. 결과 이미지 SNS/카톡 공유
4. 캐릭터별 맞춤 절약 팁 3가지
5. 리워드 광고 시청 후 상세 분석 리포트 공개
6. 친구 결과와 궁합 비교

## Monetization
- Model: ads
- Estimated MRR: $250
- Reasoning: 결과 공개 화면에 리워드 광고 게이팅을 배치, 퀴즈 특성상 공유를 통한 바이럴 유입이 커서 전환율 높은 결과게이팅 패턴에 적합
