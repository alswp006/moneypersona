# MoneyPersona

앱인토스 (Vite + React + TDS) 12개 질문으로 나의 소비 성향을 '알뜰형 다람쥐' 같은 8가지 캐릭터로 진단해주는 재테크 성향 테스트 MBTI, 성향테스트는 넘쳐나지만 정작 내 소비/저축 습관을 재미있게 진단해주는 금융형 테스트는 없어 재테크 시작 전 자기 이해가 부족함

## Tech Stack

- React 18.0.0
- TypeScript
- Vitest
